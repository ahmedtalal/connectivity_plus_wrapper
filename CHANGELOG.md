## [1.0.0]
- Initial release of `connectivity_plus_wrapper` 🎉
- Smart connectivity statuses (connected, disconnected, unstable, restored, roaming, checking).
- Transition tracking with offline duration.
- Real internet access checks with customizable test servers.
- Pre-built UI widgets (`ConnectivityBuilder`, `ConnectivityOverlay`).
- `ConnectivityAware` mixin for reactive widgets.
- Configuration options for thresholds and check intervals.
